Mancala

Jugá contra la IA, con un amigo en el mismo teléfono u online.

Cuando la tengas, abrí la app → "Jugar online" → "Entrar a una sala" y escribí:

Descargar para Android

Archivo APK para teléfonos Android

Cómo instalarla

  1. Tocá "Descargar para Android".
  2. Abrí el archivo descargado (mancala.apk).
  3. Si Android lo pide, permití "instalar apps de esta fuente".
  4. Tocá "Instalar". Las actualizaciones llegan solas, no hace falta volver a bajarla.
